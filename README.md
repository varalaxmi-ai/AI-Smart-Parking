# AI-Based Smart Parking Availability and Prediction System

## Project Description
This project uses Artificial Intelligence and Machine Learning to predict available parking slots.

## Features
- Predicts available parking slots
- Uses parking occupancy data
- Simple web interface
- Flask-based application

## Technologies Used
- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- HTML and CSS

## How to Run
1. Install the required packages.
2. Run `python app.py`
3. Open `http://127.0.0.1:5000` in a web browser.
